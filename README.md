# task26100401

进程内 USDT 批量转账库（Go），支持 PIN 复核与冻结撤销。

## 设计要点

- 每个钱包一把 `sync.Mutex`，涉及多钱包的操作按 `WalletID` 字典序统一加锁，
  避免死锁且无需全局锁；不相交钱包的转账可独立推进。
- `Transfer` 先只锁付款钱包完成预占，随后**不持锁**调用复核器；
  复核返回后按统一锁序锁定全部相关钱包，原子完成提交或释放。
- `SetFrozen(true)` 只锁目标钱包，原子撤销其全部未提交付款并释放预占，
  无需等待复核器返回；解冻不恢复旧转账（旧回调返回 `Revoked`，不再改变任何状态）。
- `Snapshot` 与提交使用同一锁序，因此观察不到部分提交。
- 不变量：可用余额 = 账面 - 预占，三者非负；全体账面 + 累计手续费 = 初始资金总额。
