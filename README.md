# usdtwallet

进程内 USDT 钱包批量转账库，支持 PIN 复核、冻结撤销与一致性快照。
金额为 USDT 最小单位的 int64（1 USDT = 1_000_000 单位）。

## API

- `NewSystem(balances)`：以钱包 ID 与初始余额构造系统。
- `Transfer(sender, recipients, verifyPIN)`：先从付款钱包预占全部本金及手续费
  （每笔收款金额的 0.1% 向上取整），预占成功后调用复核器；通过后原子提交整批。
  返回 `Success` / `Rejected` / `Revoked`（被冻结撤销）。
- `SetFrozen(wallet, frozen)`：冻结只禁止付款；设为冻结时原子撤销该钱包全部
  在途付款并释放预占，不等待复核器；解冻不恢复旧转账。
- `Snapshot(ids)`：返回指定钱包在同一逻辑时刻的账面余额、预占额、可用余额、
  累计手续费与冻结状态。

## 并发设计

- 每个钱包一把锁，无全局互斥；多钱包操作（提交、快照）按钱包 ID 字典序
  统一加锁，避免死锁，不相交钱包的转账可独立推进。
- 复核器在不持有任何锁的情况下调用，每次 Transfer 至多调用一次。
- 在途转账登记在付款钱包的 `pending` 集合中，其存废即转账的有效性：
  冻结、拒绝、提交三条路径都在付款钱包锁内检查并移除，保证预占只释放一次，
  且冻结与提交竞争时必有一方完整生效。
